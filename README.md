**ShambaSync** is a mobile-first Single Page Application (SPA) designed to digitize and simplify farm operations for Kenyan farmers. It replaces manual, fragmented record-keeping with a unified, intuitive platform to track individual livestock, batch poultry, and crop plots.

## 🚜 The Problem
Kenyan agriculture employs over 40% of the population, yet the vast majority of farms operate with manual record-keeping (notebooks, scattered spreadsheets, or memory). This data blind spot leads to preventable losses, inefficient resource allocation, delayed disease interventions, and zero visibility into true profitability. Existing software is often built for large-scale Western agribusiness, is prohibitively expensive, or fails to account for the multi-asset, mobile-first reality of Kenyan farming.

## 💡 The Solution
ShambaSync is a lightweight, cloud-ready operations platform built specifically for Kenya’s diverse agricultural landscape. It categorizes every farm asset into three universal profiles:
1. **Individual**: Tagged livestock (e.g., dairy cows).
2. **Batch**: Poultry or flocks.
3. **Plot**: Orchards or crop beds.

By digitizing the complete asset lifecycle, the platform delivers real-time dashboards, automated cost-to-yield analytics, and actionable alerts, empowering farmers to transform raw farm activity into profitable decisions.

---

## ✨ Key Features
- **Single Page Application (SPA)**: Seamless, instant page transitions without browser reloads, providing a native-app-like experience.
- **Mobile-First Responsive Design**: Built with Bootstrap 5 to ensure perfect usability on low-end smartphones commonly used in rural areas.
- **Live API Integration**: Fetches real-time local weather data to provide actionable farming insights (e.g., "Good day for planting").
- **Robust Error Handling**: User-friendly, dismissible alerts when API calls fail or form validation errors occur.


---

## 🛠️ Technologies Used
- **Frontend**: HTML5, CSS3, Vanilla JavaScript (ES6+)
- **Styling**: Bootstrap 5 (via CDN), Custom CSS (Flexbox)
- **APIs**: 
  - `GET`: Open-Meteo API  for live weather data.
  - `POST`: JSONPlaceholder (Mock API) to simulate saving new farm assets to a backend.
- **Version Control**: Git & GitHub
